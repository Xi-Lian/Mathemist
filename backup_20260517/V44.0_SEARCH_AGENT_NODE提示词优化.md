# V44.0 SEARCH_AGENT_NODE提示词优化 - 强制调用检索工具

## 🐛 问题描述

用户查询"想要分步乘法的课件"或"我想要分类加法计数原理的课件"时，系统只返回1个资源，而数据库中实际有29个相关课件。

### 根本原因

**SEARCH_AGENT_NODE没有调用检索工具**，导致：
- ❌ 向量检索根本没有执行
- ❌ 返回的结果是模型从对话历史中回忆或编造的
- ❌ 不是通过实际数据库检索得到的真实结果

### 日志证据

```
SEARCH_AGENT_NODE tool_calls 数量: 0
SEARCH_AGENT_NODE 未调用工具，模型直接回复: ...
```

## 🔍 问题分析

### 原提示词的问题（第376-378行）

```python
"3. 如果用户只是在打招呼、闲聊、确认、或者主题还很模糊，就直接对话，不要调用工具。\n"
"4. 你必须结合当前对话历史理解省略信息。如果用户这轮没重复主题，但上文已经明确主题或资源类型，要先在脑中补全后再判断。\n"
"5. 如果主题仍然不够明确，先反问确认需求，不要瞎搜。\n"
```

**问题**：
- 规则3过于保守，让模型认为"主题模糊"
- 规则5让模型过度谨慎，倾向于反问而不是检索
- 模型错误地将明确的查询（"分步乘法课件"）判断为"主题不明确"

### 用户的查询实际上非常明确

- ✅ "想要分步乘法的课件" → 主题：分步乘法，类型：课件
- ✅ "我想要分类加法计数原理的课件" → 主题：分类加法计数原理，类型：课件

这两个查询都包含了**具体的数学主题+明确的资源类型**，应该触发检索。

## 🔧 V44.0改进内容

### 修改文件：`backend/app/nodes.py`

#### 修改前（过于保守）
```python
"3. 如果用户只是在打招呼、闲聊、确认、或者主题还很模糊，就直接对话，不要调用工具。\n"
"5. 如果主题仍然不够明确，先反问确认需求，不要瞎搜。\n"
```

#### 修改后（更积极）
```python
"3. 【重要】只要用户提到具体的数学主题+资源类型（如'余弦定理课件'、'二次函数教案'、'分步乘法课件'），就必须调用 search_resources_tool，即使主题看起来很简单。\n"
"5. 只有在完全没有主题信息时（如'给我一些资源'、'我想学习'），才需要反问确认。对于有明确主题的查询，直接调用工具检索。\n"
```

### 关键改进

1. **明确触发条件**：只要包含"数学主题+资源类型"，就必须调用工具
2. **减少误判**：不再让模型主观判断"主题是否模糊"
3. **提供示例**：给出明确的示例（'余弦定理课件'、'二次函数教案'、'分步乘法课件'）
4. **限制反问场景**：只有完全没主题时才反问
