# Mathemist 后端技术架构大纲 - 商业计划书版

## 一、后端系统概述

### 1.1 系统定位
Mathemist后端是一个基于人工智能的高中数学教学资源智能辅助系统，通过大语言模型(LLM)、向量数据库和工作流编排技术，为教师提供智能化的教案生成、资源检索、可视化设计建议等一站式备课解决方案。团队在采集公开数据基础上，搭建标准化、可复用的数据处理与存储体系，综合处理与存储多种类型教学资源，增强教学系统实用性。

### 1.2 核心理念
- 模块化、可扩展的架构设计
- 基于LangGraph的智能工作流编排
- 标准化数据沉淀与语义化资源检索
- 多意图识别与并行处理能力

## 二、核心技术栈

### 2.1 Web框架与API层
- **FastAPI 0.129+**: 高性能异步Web框架，支持自动生成API文档
- **Uvicorn**: ASGI服务器，支持热重载和生产环境部署
- **Pydantic 2.0+**: 数据验证与序列化
- **LangServe**: LangChain应用服务化部署

### 2.2 AI/ML技术栈
- **LangGraph 0.1.8**: 状态机工作流编排，实现多节点协作
- **LangChain 0.3.0+**: LLM应用开发框架
- **DeepSeek**: 统一大语言模型，用于意图理解、教案生成、可视化建议
- **Sentence-Transformers**: 文本嵌入模型，用于语义检索
- **ChromaDB 0.5.23**: 向量数据库，存储和检索教学资源

### 2.3 数据处理与工具
- **NumPy/Pandas**: 数据处理与分析
- **Transformers**: Hugging Face Transformers库
- **Python-dotenv**: 环境变量管理
- **SSE-Starlette**: 服务端事件推送，支持流式响应

### 2.4 开发与测试
- **Black/Isort/Flake8**: 代码格式化与 linting
- **MyPy**: 静态类型检查
- **PyTest**: 单元测试与集成测试

### 3.2 LangGraph工作流架构

核心工作流节点:
1. **意图理解节点** - 分析用户输入，识别主意图和多意图
2. **资源检索节点** - 基于语义检索相关教学资源
3. **条件路由** - 根据意图智能路由到不同处理路径
4. **处理节点**:
   - 统一教案系统节点
   - 教案生成节点
   - 可视化建议节点
   - GGB设计顾问节点
   - 多意图处理器节点
5. **响应格式化节点** - 整合所有处理结果

### 3.3 关键设计原则
- **单一职责原则**: 每个模块只负责一个明确的功能领域
- **依赖倒置原则**: 高层模块不依赖低层模块，都依赖于抽象接口
- **开闭原则**: 对扩展开放，对修改关闭
- **可测试性**: 模块独立，便于单元测试和集成测试

## 四、核心功能模块详解

### 4.1 意图理解模块 (Intent Analyzer)
- **功能**: 基于LLM的意图识别，支持多意图检测
- **支持的意图**: 资源搜索、教案生成、可视化建议
- **技术亮点**:
  - 关键词匹配作为备用方案
  - 置信度评分机制
  - 多意图并行处理能力

### 4.2 资源检索系统
- **标准化数据处理与存储体系**: 团队在采集公开数据基础上，搭建标准化、可复用的数据处理与存储体系，规范数据沉淀，综合处理与存储多种类型教学资源，增强教学系统实用性。
- **资源表格解析器**: 解析Markdown格式的资源汇总表
  - 支持多种表格格式(标准Markdown、Excel导出、特殊格式)
  - 支持8种资源类型:教案、教学大纲、课件、课例、GGB、可视化、习题、理论卡片
- **向量数据库构建器**: 基于ChromaDB的语义索引
  - 使用Sentence-Transformers实现数据向量化
  - 支持数据库创建、更新、删除
- **资源检索器**: 智能语义检索
  - 根据查询和意图检索相关资源
  - 对检索结果进行分类和组织
  - 习题资源特殊处理逻辑

### 4.3 教案生成系统
- **统一备课系统**: 完整的备课工作流管理
  - 智能判断用户输入完整度
  - 自动选择生成或引导方式
  - 分步引导教师完成备课
- **教案生成器**:
  - 整合理论依据和优秀教案特征
  - 结构化教案输出
- **教案导出器**: 支持Markdown、HTML、Word等多格式导出

### 4.4 可视化与GGB设计系统
- **可视化顾问**: 生成专业的可视化设计建议
- **GGB设计顾问**: GeoGebra动态数学设计指导
  - 分析GGB资源并提取设计模式
  - 提供GGB文件使用和修改建议

### 4.5 用户系统
- 用户身份管理和认证
- 备课历史记录的存储和检索
- 个人备课数据管理
- 用户个性化配置
- JSON文件持久化存储
