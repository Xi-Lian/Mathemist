# 2026-05-21 工作日志

## 习题结构化展示方案 — 路线一（后端 + 前端）实施完成

### 问题
后端习题检索时结构化字段（question/answer/knowledge_tags 等）在 resource 字典中存在，但最终展示时被拼接为 content 字符串，前端无法分区渲染。

### 后端实施（已完成）
1. **`search_agent_runtime.py`**：新增 `extract_exercise_details()` 函数，从 `retrieved_resources.exercise_resources` 提取结构化字段
2. **`state.py`**：`MathAgentState` 新增 `exercise_details: List[Dict[str, Any]]` 字段
3. **`nodes.py`**：`response_formatting_node` 调用 `extract_exercise_details` 并输出到 state
4. **`main.py`**：`/math-agent/invoke` 和 `/generate-lesson-plan` 端点响应中附带 `exercise_details`

### 前端实施（已完成）
5. **`Stream.tsx`**：新增 `ExerciseDetail` 类型定义，`StateType` 和 `useTypedStream` UpdateType 中加入 `exercise_details`
6. **`exercise-card.tsx`**（新建）：结构化习题卡片组件，支持：
   - 题目类型徽章 + 难度星级 + 相关性百分比
   - 题干展示（文字/图片自适应）
   - 知识点标签行
   - 解析默认折叠，"查看解析"按钮展开（带动画）
   - 图片习题支持（question_image_url / answer_image_url）
   - 来源文件信息脚注
   - 多习题时显示序号（1/N）
7. **`ai.tsx`**：`AssistantMessage` 中集成 `ExerciseCardList`，当 `isLastMessage && exercise_details` 非空时渲染在 MarkdownText 之后

### 效果
- 前端从 SSE state 或 API JSON 中直接获取 `exercise_details`
- 习题展示从"大段 Markdown 文本"变为分区卡片（题目区 + 知识点标签 + 解析折叠区）
- 不影响检索效果（只改展示层输出）
- 向后兼容：`response` 和 `retrieved_resources` 保持不变，无 exercise_details 时维持原有 Markdown 渲染
