# V48.4 修改请求判断优化 - 避免误判全新需求

## 🐛 问题描述

**用户输入**：
```
下周有个示范课观摩活动，主题是概率统计，需要规范的教案
```

**系统错误行为**：
```
✏️ 检测到修改意见
🔄 检测到修改意见，从最新教案恢复会话: lp_xxxxxxxx
好的，教案已经根据您提供的信息（高一、1课时、日常教学）完整生成了！
当前版本涵盖了从教学目标、重难点分析到详细教学过程...
您可以：
1. **查看完整教案**：直接阅读上方生成的《函数的单调性》教学设计全文。
```

**根本原因**：
1. 用户输入中包含"需要"这个词
2. "需要"在`REVISION_KEYWORDS`列表中（第9行）
3. 系统误判为修改请求
4. 从最新教案（函数单调性）恢复会话
5. 生成的是旧教案的修改版，而不是全新的概率统计教案

---

## ✅ 修复方案

### 修复：优先检查生成关键词

**文件**: `backend/app/core/unified_lesson_plan/process_helpers/intent_flow.py`

**修改前**（第21-26行）：
```python
def handle_revision_request(system, user_input, session_id):
    has_revision_request = any(keyword in user_input for keyword in REVISION_KEYWORDS)
    if not has_revision_request and any(keyword in user_input for keyword in GENERATION_KEYWORDS):
        has_revision_request = False
    if not has_revision_request:
        return None, session_id
```

**修改后**：
```python
def handle_revision_request(system, user_input, session_id):
    # V48.4修复：先检查是否包含生成关键词，如果是则不是修改请求
    has_generation_keyword = any(keyword in user_input for keyword in GENERATION_KEYWORDS)
    if has_generation_keyword:
        print(f"✅ 检测到生成关键词，跳过修改请求判断")
        return None, session_id
    
    has_revision_request = any(keyword in user_input for keyword in REVISION_KEYWORDS)
    if not has_revision_request:
        return None, session_id
```

**关键改进**：
- ✅ **优先级调整**：先生成关键词检查，再修改关键词检查
- ✅ **早期返回**：如果检测到生成关键词，立即返回None，不进行后续判断
- ✅ **明确日志**：输出"检测到生成关键词"，便于调试

## 💡 技术细节

### 关键词列表

**GENERATION_KEYWORDS**（第14行）：
```python
GENERATION_KEYWORDS = ["生成", "创建", "新建", "制作", "写一份", "来一份"]
```

**REVISION_KEYWORDS**（第5-13行）：
```python
REVISION_KEYWORDS = [
    "觉得", "感觉", "认为", "希望", "想要", "需要", "应该", "建议", "提议",
    "修改", "调整", "改进", "完善", "优化", "补充", "增加", "添加", "减少", "删除",
    ...
]
```

### 判断逻辑

**修复前的逻辑**：
```python
has_revision = check_revision_keywords()
if not has_revision and check_generation_keywords():
    has_revision = False  # 后置修正
```

**问题**：
- "需要"同时出现在两个列表中
- 先检查修改，再检查生成
- 导致误判

**修复后的逻辑**：
```python
if check_generation_keywords():
    return None  # 早期返回，优先处理生成请求

has_revision = check_revision_keywords()
if not has_revision:
    return None
```

**优势**：
- 生成请求优先级更高
- 避免关键词冲突
- 逻辑更清晰

### 2. 关键词权重

给不同关键词赋予不同的权重：

```python
REVISION_KEYWORDS_WEIGHTS = {
    "修改": 1.0,
    "调整": 0.9,
    "需要": 0.3,  # 低权重，容易误判
    "希望": 0.3,
}

def calculate_revision_score(user_input: str) -> float:
    score = 0
    for keyword, weight in REVISION_KEYWORDS_WEIGHTS.items():
        if keyword in user_input:
            score += weight
    return score
```

def is_revision_in_context(user_input: str, conversation_history: list) -> bool:
