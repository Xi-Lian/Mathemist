# V48.8 useSearchParams Hydration 错误修复

## 🐛 问题描述

**错误信息**：
```
A tree hydrated but some attributes of the server rendered HTML didn't match the client properties.
...
<h1 className="mb-5 text-center text-2xl font-semibold md:text-3xl">
  画图建议 + 图形库
</h1>
```

**根本原因**：
- 组件使用了 `useSearchParams()` 获取 URL 查询参数
- 在 **Next.js SSR** 环境中：
  - **服务器端**：`searchParams.get("apiUrl")` 可能返回 `null` 或空值
  - **客户端**：`searchParams.get("apiUrl")` 能获取完整的查询参数
- 导致 `apiBaseUrl` 的初始值在服务器和客户端不一致
- 引发 Hydration 错误

---

## ✅ 修复方案

### 修复：延迟初始化依赖查询参数的状态

**文件**: `frontend/src/components/geometry/CombinedGeometryWorkbench.tsx`

**修改前**（第24-29行）：
```tsx
export function CombinedGeometryWorkbench() {
  const searchParams = useSearchParams();
  const initialApiFromQuery = searchParams.get("apiUrl")?.trim() ?? "";
  const [apiBaseUrl, setApiBaseUrl] = useState(
    initialApiFromQuery || process.env.NEXT_PUBLIC_API_URL || "http://localhost:8000",
  );
  // ...
}
```

**修改后**：
```tsx
import { useEffect, useMemo, useState } from "react";  // 添加 useEffect

export function CombinedGeometryWorkbench() {
  const searchParams = useSearchParams();
  // V48.8修复：使用 useState + useEffect 避免 Hydration 不匹配
  const [apiBaseUrl, setApiBaseUrl] = useState("http://localhost:8000");
  const [isMounted, setIsMounted] = useState(false);
  
  // 在客户端挂载后初始化 apiBaseUrl
  useEffect(() => {
    const initialApiFromQuery = searchParams.get("apiUrl")?.trim() ?? "";
    setApiBaseUrl(
      initialApiFromQuery || process.env.NEXT_PUBLIC_API_URL || "http://localhost:8000",
    );
    setIsMounted(true);
  }, [searchParams]);
  // ...
}
```

**关键改进**：
- ✅ 服务器端渲染时使用默认值 `"http://localhost:8000"`
- ✅ 客户端挂载后通过 `useEffect` 更新为实际值
- ✅ 确保服务器和客户端初始渲染一致

## 📊 技术原理

### Next.js SSR 中的 useSearchParams

**服务器端渲染流程**：
```
1. 用户请求页面
2. Next.js 在服务器端渲染组件
3. useSearchParams() 可能无法获取完整查询参数
4. 生成 HTML 发送给浏览器
```

**客户端水合流程**：
```
1. 浏览器接收 HTML
2. React 加载 JavaScript bundle
3. 客户端重新渲染组件
4. useSearchParams() 获取完整查询参数
5. 如果与服务器渲染不一致 → Hydration 错误 ❌
```

---

### 修复后的流程

**服务器端**：
```tsx
const [apiBaseUrl, setApiBaseUrl] = useState("http://localhost:8000");
// 渲染时使用默认值
return <Input value="http://localhost:8000" />;
```

**客户端挂载后**：
```tsx
useEffect(() => {
  // 从 URL 查询参数获取实际值
  const apiUrl = searchParams.get("apiUrl");
  setApiBaseUrl(apiUrl || "http://localhost:8000");
}, [searchParams]);
// React 更新 DOM，无 Hydration 错误 ✅
```

## 🎯 useSearchParams 最佳实践

### ❌ 错误用法

```tsx
// 直接在渲染时使用 searchParams
export function MyComponent() {
  const searchParams = useSearchParams();
  const value = searchParams.get("key");  // ❌ 可能导致 Hydration 错误
  
  return <div>{value}</div>;
}
```

---

### ✅ 正确用法 1：使用 useEffect

```tsx
export function MyComponent() {
  const searchParams = useSearchParams();
  const [value, setValue] = useState("");
  
  useEffect(() => {
    setValue(searchParams.get("key") || "");
  }, [searchParams]);
  
  return <div>{value}</div>;
}
```

---

### ✅ 正确用法 2：使用 Suspense

```tsx
import { Suspense } from "react";
import { useSearchParams } from "next/navigation";

function SearchParamsContent() {
  const searchParams = useSearchParams();
  const value = searchParams.get("key");
  
  return <div>{value}</div>;
}

export function MyComponent() {
  return (
    <Suspense fallback={<div>Loading...</div>}>
      <SearchParamsContent />
    </Suspense>
  );
}
```

**注意**：Suspense 会让组件在客户端完全渲染后再显示，避免 Hydration 问题。

---

### ✅ 正确用法 3：使用 generateMetadata（静态生成）

如果是静态页面，可以在 `generateMetadata` 中处理：

```tsx
export async function generateMetadata({ searchParams }: Props) {
  const key = await searchParams.key;
  return {
    title: `Page - ${key}`,
  };
}
```

## 💡 其他常见 Hydration 错误场景

### 1. 使用 Date.now() 或 Math.random()

**错误**：
```tsx
<p>{Date.now()}</p>  // ❌ 每次渲染都不同
```

**修复**：
```tsx
const [timestamp, setTimestamp] = useState<number | null>(null);

useEffect(() => {
  setTimestamp(Date.now());
}, []);

if (timestamp === null) return null;
return <p>{timestamp}</p>;
```

---

### 2. 浏览器 API 依赖

**错误**：
```tsx
<p>{window.innerWidth}</p>  // ❌ 服务器端没有 window
```

**修复**：
```tsx
const [width, setWidth] = useState(0);

useEffect(() => {
  setWidth(window.innerWidth);
}, []);

return <p>{width}</p>;
```

---

### 3. LocalStorage/SessionStorage

**错误**：
```tsx
const value = localStorage.getItem("key");  // ❌ 服务器端没有 localStorage
```

**修复**：
```tsx
const [value, setValue] = useState<string | null>(null);

useEffect(() => {
  setValue(localStorage.getItem("key"));
}, []);

if (value === null) return null;
return <div>{value}</div>;
```

---

### 4. 条件渲染基于环境变量

**错误**：
```tsx
{process.env.NODE_ENV === "development" && <DevTools />}
```

**修复**：
```tsx
const [isDev, setIsDev] = useState(false);

useEffect(() => {
  setIsDev(process.env.NODE_ENV === "development");
}, []);

return isDev ? <DevTools /> : null;
```

## 🚀 性能优化建议

### 1. 避免不必要的重渲染

```tsx
// ❌ 每次 searchParams 变化都重新执行
useEffect(() => {
  // 大量计算
}, [searchParams]);

// ✅ 只监听需要的参数
useEffect(() => {
  const apiUrl = searchParams.get("apiUrl");
  setApiBaseUrl(apiUrl || "http://localhost:8000");
}, [searchParams.get("apiUrl")]);  // 只监听特定参数
```

---

### 2. 使用 useMemo 缓存计算结果

```tsx
const normalizedUrl = useMemo(() => {
  return apiBaseUrl.endsWith("/") 
    ? apiBaseUrl.slice(0, -1) 
    : apiBaseUrl;
}, [apiBaseUrl]);
```

---

### 3. 延迟加载重型组件

```tsx
const [loaded, setLoaded] = useState(false);

useEffect(() => {
  // 延迟加载重型组件
  import("./HeavyComponent").then((module) => {
    setHeavyComponent(module.default);
    setLoaded(true);
  });
}, []);

if (!loaded) return <Skeleton />;
return <HeavyComponent />;
```
