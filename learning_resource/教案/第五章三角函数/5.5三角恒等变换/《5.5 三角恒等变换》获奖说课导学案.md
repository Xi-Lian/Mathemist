**问题探究**

**１.两角差的余弦公式**

如果已知任意角α，β的正弦、余弦，能由此推出α＋β，α－β的正弦、余弦吗？

下面，我们来探究cos(α－β)与角α，β的正弦、 余弦之间的关系

![](media/image6.png){width="2.5413484251968503in" height="2.405949256342957in"}

不妨令$\alpha \neq 2$kπ＋β，k∈Z． 如图5.5.1，设单位圆与$x$轴的正半轴相交于点A（１，０），以$x$轴非负半轴为始边作角α，β，α---β， 它们的终边分别与单位圆相交于点$A_{1}$（cosα，sinα）， $P_{1}$（cosβ，sinβ），P(cos(α－β)，sin(α－β))．任意一个圆绕着其圆心旋转任意角后都与原来的圆重合，这一性质叫做圆的旋转对称性．连接$A_{1}P_{1}$，AP．若把扇形OAP,绕着点O旋转β角，则点A，P分别与点$A_{1},$ $P_{1}$重合．根据圆的旋转对称性可知，

$\widehat{AP}$与$\widehat{{A_{1}P}_{1}}\ $重合，从而， 所以AP＝${A_{1}P}_{1}$

根据两点间的距离公式，得

$\left\lbrack \cos(\alpha - \beta) - 1 \right\rbrack^{2}$+$\left\lbrack s{in(\alpha - \beta)} \right\rbrack^{2}$=${({\cos\alpha -}{cos\beta})}^{2}$+${({\sin\alpha -}{sin\beta})}^{2}$，\
化简得:\
$\cos(\alpha - \beta)$=${\cos\alpha}{cos\beta}$+${\sin\alpha}{sin\beta}$\
当$\alpha = 2$kπ＋β （k∈Z）时，容易证明上式仍然成立．\
所以，对于任意角α，β有\
$\cos(\alpha - \beta)$=${\cos\alpha}{cos\beta}$+${\sin\alpha}{sin\beta}$ （Ｃ（α－β））\
此公式给出了任意角α，β的正弦、余弦与其差角α－β的余弦之间的关系，

称为差角的余弦公式，简记作Ｃ(α－β).

**典例解析**

例１ 利用公式$\cos(\alpha - \beta)$证明：\
（１）$\cos\left( \frac{\mathbf{\pi}}{\mathbf{2}}\text{-}\alpha \right)$= $\sin\alpha$ ; （２）$\cos\left( \mathbf{\pi}\text{-}\alpha \right)$= $\cos\alpha$．

**例２** 已知${sin\alpha =}\frac{4}{5}$，$\alpha$∈($\frac{\mathbf{\pi}}{\mathbf{2}}$,$\mathbf{\pi}$), ${\cos\beta = -}\frac{5}{13}$，$\beta$是第三象限角，求$\cos(\alpha - \beta)$的值．

由公式 $\cos(\alpha - \beta)$出发 ， 你能推导出两角和与差的三角函数的其他公式吗？

下面以公式 $\cos(\alpha - \beta)$为基础来推导其他公式 ．

例如 ， 比较$\cos(\alpha - \beta)$ 与$\cos(\alpha + \beta)$ ，并注意到 α ＋ β 与

$\alpha - \beta$之间的联系 ：$\alpha + \beta$＝$\alpha - （ - \beta ）$则由公式 $\cos(\alpha - \beta)$ ，

有$\cos(\alpha + \beta)$=$\cos{\lbrack\alpha - ( - \beta)\rbrack\ }$＝${\cos\alpha}{\cos( - \beta)}$+${\sin\alpha}{\sin( - \beta)}$=${\cos\alpha}{cos\beta}{- \sin\alpha}{sin\beta}$

于是得到了两角和的余弦公式 ， 简记作 C（α ＋ β ） ．

$\cos(\alpha + \beta)$=${\cos\alpha}{cos\beta}{- \sin\alpha}{sin\beta}$．

**问题探究**

上面得到了两角和与差的余弦公式 ． 我们知道 ， 用诱导公式五 （ 或六 ） 可以实现正弦 、 余弦的互化 ． 你能根据 Ｃ （α ＋ β ） ， Ｃ （ α － β ） 及诱导公式五 （ 或六 ）， 推导出用任意角α ， β 的正弦 、 余弦表示 sin （ α ＋ β ）， sin（ α － β ） 的公式吗 ？

通过推导 ， 可以得到 ：

${\ \ \ s}{in(\alpha + \beta)}$ ＝ $\sin\alpha cos\beta + {\cos\alpha sin\beta}$，（ S（α ＋ β ） ）

${\ \ \ s}{in(\alpha - \beta)}$ ＝ $\sin\alpha cos\beta - {\cos\alpha sin\beta}$ ; （ S（α － β ） ）

你能根据正切函数与正弦函数 、 余弦函数的关系 ， 从 Ｃ(α ± β ) ， Ｓ( α ± β ) 出发 ， 推导出用任意角 α ， β 的正切表示${\ \ \ \tan}(\alpha + \beta)$ ，${\ \ \ \tan}(\alpha - \beta)$ 的公式吗 ？

${\ \ \ \ \ \ \ \tan}(\alpha + \beta)$ $= \frac{{\ \ \ \tan}{\alpha +}tan\beta}{{\ \ \ 1 -}{{\ \ \ \tan}\alpha tan\beta}}$ T(α + β )
