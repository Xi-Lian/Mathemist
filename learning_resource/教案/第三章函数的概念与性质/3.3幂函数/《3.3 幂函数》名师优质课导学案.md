知识点三　一般幂函数的图象特征

1．所有的幂函数在(0，＋∞)上都有定义，并且图象都过点[(1,1)．]{.underline}

2．当*α*\>0时，幂函数的图象通过[原点]{.underline}，并且在区间\[0，＋∞)上是[增]{.underline}函数．特别地，当*α*\>1时，幂函数的图象[下凸]{.underline}；当0\<*α*\<1时，幂函数的图象[上凸．]{.underline}

3．当[*α*\<0]{.underline}时，幂函数的图象在区间(0，＋∞)上是减函数．

4．幂指数互为倒数的幂函数在第一象限内的图象关于直线*y*＝*x*对称．

5．在第一象限，作直线*x*＝*a*(*a*\>1)，它同各幂函数图象相交，按交点从下到上的顺序，幂指数按从[小]{.underline}到[大]{.underline}的顺序排列．
