> 5.公式五: 终边关于直线y＝x对称的角的诱导公式(公式五)：
>
> $\sin\left( 90^{0} - \alpha \right) = \sin\left( \frac{\pi}{2} - \alpha \right) = cos\alpha$；
>
> c$\cos\left( 90^{0} - \alpha \right) = \cos\left( \frac{\pi}{2} - \alpha \right) = sin\alpha$.
>
> 6、公式六:＋α型诱导公式(公式六)：
>
> $\sin\left( 90^{0} + \alpha \right) = \sin\left( \frac{\pi}{2} + \alpha \right) = cos\alpha$；
>
> c$\cos\left( 90^{0} + \alpha \right) = \cos\left( \frac{\pi}{2} + \alpha \right) = - sin\alpha$.

**【说明】**：①公式中的$\alpha$指任意角；②在角度制和弧度制下，公式都成立；

> ③记忆方法： "奇变偶不变，符号看象限"；

**【方法小结】**：用诱导公式可将任意角的三角函数化为锐角的三角函数，其一般方向是：

> ①化负角的三角函数为正角的三角函数；
>
> ②化为\[0,2$\pi$\]内的三角函数；
>
> ③化为锐角的三角函数。

可概括为："负化正，大化小，化到锐角为终了"（有时也直接化到锐角求值）。
