知识点一　函数奇偶性的几何特征

一般地，图象关于*y*轴对称的函数称为[偶]{.underline}函数，图象关于原点对称的函数称为[奇]{.underline}函数．

知识点二　函数奇偶性的定义

1．偶函数：函数*f*(*x*)的定义域为*I*，如果∀*x*∈*I*，都有－*x*∈*I*，且[*f*(－*x*)＝*f*(*x*)]{.underline}，那么函数*f*(*x*)就叫做偶函数．

2．奇函数：函数*f*(*x*)的定义域为*I*，如果∀*x*∈*I*，都有－*x*∈*I*，且[*f*(－*x*)＝－*f*(*x*)]{.underline}，那么函数*f*(*x*)就叫做奇函数．

知识点三　奇(偶)函数的定义域特征

奇(偶)函数的定义域关于[原点]{.underline}对称．

![](media/image4.png)

1．奇、偶函数的定义域都关于原点对称．(　√　)

2．函数*f*(*x*)＝*x*^2^＋\|*x*\|的图象关于原点对称．(　×　)

3．对于定义在**R**上的函数*f*(*x*)，若*f*(－1)＝*f*(1)，则函数*f*(*x*)一定是偶函数．(　×　)

4．不存在既是奇函数又是偶函数的函数．(　×　)
