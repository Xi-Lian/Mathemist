## 排查"分类加法计数原理的练习课课件"无结果问题

### 数据库状况
- 主数据库路径: `backend/chroma_db`
- 计数原理相关课件(courseware): **16 条**，均在 `math_resources_probability` 集合
- 其中教学用途为"练习课课件"的有：
  - `6.1 分类加法计数原理与分步乘法计数原理`（教学用途: 练习课课件）
  - `习题课  计数原理`（教学用途: 练习课课件）
- 数据库里**有目标资源**，问题在检索流程

### 根本原因：三处链式故障

1. **资源类型误判（`extract_resource_types.py`）**
   - `"练习"` 是"习题"类型的触发词之一
   - "练习课课件"中的 `"练习"` 字 → 错误触发"习题"类型
   - 结果：`resource_types = ['习题', '课件']`（双类型）
   - 实际应为：`resource_types = ['课件']`

2. **向量相似度低（根本原因）**
   - 目标课件标题简单（如"6.1 分类加法计数原理与分步乘法计数原理"）
   - 查询包含"练习课"这个教学用途词，但向量语义不含该信息
   - 向量检索 top-K 可能根本没命中这16条 courseware

3. **`教学用途` 字段未参与向量检索**
   - 课件的 `教学用途` 字段值是"练习课课件"
   - 但该字段可能没有被建入向量文本，导致语义搜索无法通过"练习课"找到
   - `_specific_query_score` 中已有 `teaching_use` 参与评分（V41.6），
     但这是后处理阶段，只对已召回结果生效，无法弥补向量召回阶段的缺失

### 修复建议
1. **`extract_resource_types.py`**: "练习"触发词应加上排除条件，当"练习"后面紧跟"课"时不应触发习题类型
   ```python
   # 当前: "练习" 在 "习题" 关键词列表中
   # 修复: 检测到 "练习课" 时跳过，或只匹配单独的"练习"/"练习题"
   ```
2. **向量文本构建**: 检查课件资源的向量文本是否包含 `教学用途` 字段

### 待验证
- [ ] 确认向量文本构建脚本（build_database.py）是否将 `教学用途` 写入文档文本

## 实现课件教学用途识别与过滤（V53.0）

### 需求
用户查询如"分类加法计数原理的练习课课件"时，系统应：
1. 识别资源类型为课件（不误触发习题）
2. 提取教学用途（练习课/复习课/新授课/习题课）
3. 用教学用途过滤课件结果

### 改动文件
1. **`extract_resource_types.py`**（Bug修复 + 功能）
   - 新增 `_COURSEWARE_TEACHING_USE_PATTERNS` 检测"练习课"/"复习课"等
   - 当输入含教学用途模式时，"练习"/"复习"不触发习题类型
   - 自动补入"课件"类型

2. **`extract_courseware_teaching_use.py`**（新文件）
   - 新 Mixin `_ExtractCoursewareTeachingUseMixin`
   - 方法 `_extract_courseware_teaching_use(user_input)` 返回识别到的教学用途或 None
   - "复习"单词需配合课件信号词才触发（避免"复习一下"误触）

3. **`intent/service.py`**
   - 引入新 Mixin，加入 `IntentAnalyzer` 继承链

4. **`intent/methods/analyze.py`**
   - `analyze()` 返回 result 中加入 `courseware_teaching_use` 字段

5. **`state.py`**（`MathAgentState`）
   - 新增 `courseware_teaching_use: Optional[str] = None` 字段

6. **`retrieval/retrieve_helpers/postprocess.py`**
   - 新增 `apply_courseware_teaching_use_filter(results, courseware_teaching_use)` 函数
   - 按 `教学用途` 字段过滤课件；全清空时回退保留全部课件

7. **`retrieval/methods/retrieve.py`**
   - `retrieve()` 新增 `courseware_teaching_use` 参数
   - import 加入新过滤函数
   - 在 postprocess 链头部调用过滤

8. **`nodes.py`**（`resource_retrieval_node`）
   - 从 state 读取 `courseware_teaching_use` 并传入 `retriever.retrieve()`
