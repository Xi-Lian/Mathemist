# V45.1 课例视频标题修复 - 使用课程名称作为标题

## 🐛 问题描述

用户查询"想要关于简单随机抽样的课例视频"时，返回的结果显示：

```
**🎬 ⭐ 课例: 第二章，一元二次函数、方程和不等式**
- 适配说明：核心匹配；主题：简单随机抽样
```

**问题**：
- ❌ 标题显示的是"第二章，一元二次函数、方程和不等式"（这是错误的）
- ✅ 但实际内容是关于"简单随机抽样"的
- ❌ 标题和内容不匹配，误导用户

## 🔍 根本原因

### 1. Excel源文件数据

在`概率与统计-课例视频.xlsx`中：
- ✅ **课程名称**: "9.1.1简单随机抽样(一)" （正确）
- ❌ **章节**: "第二章，一元二次函数、方程和不等式" （Excel中的错误，应该是第九章）
- ✅ **视频文件名/网址**: 有正确的URL
- ✅ **分析**: 包含正确的教学内容

### 2. 导入代码的问题

在`backend/app/core/resource_table/methods/parse_lesson_case_table.py`中，标题构建逻辑：

```python
# ❌ 错误的逻辑
chapter = item.get('章节', '')  # 获取章节（错误的：一元二次函数）
filename = item.get('视频文件名/网址', '')
analysis = item.get('分析', '')
title_parts = []
if chapter:
    title_parts.append(chapter)  # ❌ 使用了错误的章节
if filename and not filename.startswith('http'):
    title_parts.append(filename)
if analysis:
    title_parts.append(analysis[:20])
title = ' - '.join(title_parts)
item['title'] = title
```

**结果**：标题变成了"第二章，一元二次函数、方程和不等式 - ..."，而不是"9.1.1简单随机抽样(一)"

### 关键改进

1. **优先使用"课程名称"字段**：这是最准确的标题来源
2. **降级策略**：如果没有课程名称，才使用章节+文件名的组合
3. **移除分析字段**：不再将分析内容的前20个字符添加到标题中，避免标题过长
4. **两处修复**：同时修复了本地文件解析和云端文件解析的逻辑
